# Internal linking map

## Principle
Links are contextual and descriptive (e.g. "explore our 4-day workout splits", "Build This Split in the Planner"). Every important page is reachable through plain crawlable `<a href>` links; the audit fails on broken links and flags orphans.

## Graph
```
Home ─► Split Finder ─► Recommended split ─► Planner (?split=&days=)
 │            ▲                │
 │            │                ├─► Exercises ─► Muscle page ─► Planner (?cat=)
 ▼            │                └─► Day-based pages (2–7 day)
Workout Splits hub ─► Types · Day pages · Best Workout Split · Finder
Exercise ─► Muscle · Alternatives · Splits · Planner (?add=)
Muscle   ─► Exercises · Splits (3 relevant) · Planner (?cat=)
Calculator ─► Goal-based Finder · other calculators · Methodology
Comparison/Guide ─► Finder · Planner (Phase 2)
```

## Contextual CTA component (`src/components/CTA.astro`)
| Variant | Primary CTA | Destination |
|---|---|---|
| exercise | Add This Exercise to Your Workout → | `/workout-planner?add={slug}` |
| muscle | Build a Workout for This Muscle → | `/workout-planner?cat={Muscle}` |
| split | Build This Split in the Planner → | `/workout-planner?split={slug}` |
| comparison | Find Which Split Fits You → | `/workout-split-finder` |
| calculator | Find a Workout Split for Your Goal → | `/workout-split-finder` |
| guide | Build Your Workout → | `/workout-planner` |
| generic | Find My Best Split → | `/workout-split-finder` |

## Data-driven links (one dataset, no duplicated lists)
- Exercise → muscle page via `MUSCLE_PAGES` (`src/lib/seo.ts`); exercise → splits via `relatedSplits`; exercise → alternatives via `alternatives`.
- Split pages → day pages, finder, muscle guide, exercise library.
- Day pages → matching split type pages, planner templates, exercise pages (examples), finder with `days=` preset.

## Measured contextual inbound links (from page content, excluding nav/footer)
See the table at the top of `docs/seo-audit.md` (regenerated by `npm run audit:seo -- --write docs/seo-audit.md`). Watch `/guides`, `/calculators` and `/methodology` — currently reached mostly via footer/nav; Phase 2 should add contextual links from the hub and exercise pages.

## Rules
- Do not add long "related pages" lists to every page; link where the next step is natural.
- New pages must be added to: sitemap generator, keyword map, and at least two contextual inbound links.
